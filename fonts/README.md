# Fonts Directory

This directory should contain the following WOFF2 font files for the V2 design:

## Required Files

1. **Cabinet Grotesk** (from [Fontshare](https://www.fontshare.com/fonts/cabinet-grotesk))
   - `cabinet-grotesk-700.woff2`
   - `cabinet-grotesk-800.woff2`

2. **Satoshi** (from [Fontshare](https://www.fontshare.com/fonts/satoshi))
   - `satoshi-400.woff2`
   - `satoshi-500.woff2`
   - `satoshi-700.woff2`

3. **Geist Mono** (from [Google Fonts](https://fonts.google.com/specimen/Geist+Mono))
   - `geist-mono-400.woff2`
   - `geist-mono-500.woff2`

4. **Noto Sans Tamil** (from [Google Fonts](https://fonts.google.com/noto/specimen/Noto+Sans+Tamil))
   - `noto-sans-tamil-400.woff2`
   - `noto-sans-tamil-600.woff2`

## Fallback

Until these fonts are added, the site will use `system-ui, sans-serif` as the fallback (set via `font-display: swap` in `css/tokens.css`).
